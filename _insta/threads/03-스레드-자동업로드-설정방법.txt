■ 스레드 자동 업로드 설정 방법 (처음 한 번만)
■ 컴퓨터(크롬)로 하시는 걸 추천해요. 20~30분 걸려요
■ 비밀번호 · 토큰은 절대 채팅으로 보내지 마세요. 마지막에 GitHub에만 넣어요
■ Meta 화면 메뉴 이름은 가끔 바뀌어요. 아래와 다르게 보이면 그 화면 캡처를 보내 주세요 (토큰 값이 보이면 가리고)

════════════════════════════════
0단계. 스레드 계정 만들기
════════════════════════════════
1. 휴대폰에 'Threads' 앱 설치
2. 인스타 @deurium 계정으로 로그인 → 프로필 만들기
3. 프로필은 '공개'로 두기 (비공개면 토큰 연장이 안 될 수 있어요)


════════════════════════════════
1단계. Meta 개발자 가입
════════════════════════════════
1. https://developers.facebook.com 접속
2. 오른쪽 위 [로그인] → 페이스북 계정으로 로그인
   (인스타 연결 때 쓰신 계정과 같은 걸로)
3. 처음이면 [시작하기] → 휴대폰 인증 → 이메일 확인 → 직업 '개발자/기타' 선택 → 완료
   (이미 인스타 때 가입하셨으면 건너뛰기)


════════════════════════════════
2단계. 앱 만들기
════════════════════════════════
1. 오른쪽 위 [내 앱] → [앱 만들기]
2. 앱 이름 : deurium-threads  /  이메일 : 사장님 이메일 → [다음]
3. 사용 사례 선택 화면에서
   'Threads API 액세스' (영문: Access the Threads API) 체크 → [다음]
4. 비즈니스 연결 화면 → '아직 비즈니스 포트폴리오를 연결하지 않겠습니다' → [다음]
5. 끝까지 [다음] → [앱 만들기] → 페이스북 비밀번호 한 번 더 입력


════════════════════════════════
3단계. 권한 켜기
════════════════════════════════
1. 왼쪽 메뉴 [사용 사례] → 'Threads API 액세스' 옆 [맞춤 설정]
2. [권한] 탭에서
   · threads_basic             → 이미 추가됨
   · threads_content_publish   → [추가] 클릭
3. [설정] 탭에서 아래 3칸에 모두 똑같이 입력 후 [저장]
   · 리디렉션 콜백 URL        : https://gyeolnbit.co.kr/
   · 앱 제거 콜백 URL         : https://gyeolnbit.co.kr/
   · 삭제 콜백 URL            : https://gyeolnbit.co.kr/
   (필수 칸이라 홈페이지 주소를 넣는 거예요. 실제로 쓰이진 않아요)


════════════════════════════════
4단계. 내 스레드 계정을 '테스터'로 등록
════════════════════════════════
1. 왼쪽 메뉴 [앱 역할] → [역할]
2. [사람 추가] → 'Threads 테스터' 선택
3. 스레드 아이디 deurium 입력 → [추가]

  ▶ 초대 수락 (컴퓨터에서)
4. 새 탭에서 https://www.threads.com 접속 → @deurium 로그인
5. 바로 이 주소로 이동 : https://www.threads.com/settings/account
6. [웹사이트 권한] → [초대] → deurium-threads 앱 [수락]


════════════════════════════════
5단계. 토큰 만들기
════════════════════════════════
1. 개발자 사이트로 돌아가서
   [사용 사례] → 'Threads API 액세스' [맞춤 설정] → [설정] 탭
2. 아래쪽 '사용자 토큰 생성기' (User Token Generator)에서
   deurium 옆 [액세스 토큰 생성] 클릭
3. 스레드 로그인 창이 뜨면 → 허용
4. 긴 글자(토큰)가 나오면 → [복사]
   ※ 이 값은 아무 데도 붙여넣지 말고 바로 6단계로

  ▶ '사용자 토큰 생성기'가 안 보이면
     그 화면을 캡처해서 보내 주세요 (다른 방법으로 안내해 드릴게요)


════════════════════════════════
6단계. GitHub에 토큰 넣기 (FTP · 인스타 넣었던 곳)
════════════════════════════════
1. https://github.com/gyuchan5979-dot/test/settings/secrets/actions 접속
2. [New repository secret] 클릭
3. Name   : THREADS_ACCESS_TOKEN
   Secret : 5단계에서 복사한 토큰 붙여넣기
4. [Add secret]


════════════════════════════════
7단계. 저한테 알려주기
════════════════════════════════
채팅에 "스레드 등록했어" 라고만 보내 주세요.
→ 제가 연결 확인(check) 후, 첫 글(인사 글) 올려서 확인해 드릴게요.

그리고 올리는 방식도 알려주세요
· A : 매일 정해진 시간 1개씩 자동 (예: "A, 저녁 8시")
· B : 제가 "올려줘" 할 때만
